# 一、GitHub 是什么？

## What is GitHub?

**中文：**
GitHub 是一个基于 Git 的代码托管平台，用于版本控制、协作开发、CI/CD 和项目管理。

**English:**
GitHub is a Git-based platform for version control, collaboration, CI/CD, and project management.

---

# 二、核心概念（必须掌握）

## Core Concepts

| 概念                | 中文解释       | English              |
| ----------------- | ---------- | -------------------- |
| Repository (Repo) | 仓库，存代码的地方  | Code container       |
| Commit            | 一次代码提交记录   | Snapshot             |
| Branch            | 分支，用于开发新功能 | Parallel development |
| Merge             | 合并分支       | Combine changes      |
| Pull Request (PR) | 代码审查与合并请求  | Code review request  |
| Fork              | 复制他人仓库     | Copy repo            |
| Clone             | 下载仓库到本地    | Local copy           |

# 三、安装与配置 Git

## Install & Configure Git

### 1. 安装 Git

👉 官网：Git

---

### 2. 配置用户信息

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

检查：

```bash
git config --global --list
```

---

# 四、创建 GitHub 仓库

## Create Repository

### 方法1：网页创建（推荐新手）

进入：GitHub

步骤：

1. 点击 **New repository**
2. 填写：

   * Repo name
   * Description
3. 选择：

   * Public / Private
4. 点击 Create

---

# 五、本地项目上传到 GitHub（重点）

## Upload Local Project to GitHub

### 场景：你已有一个项目文件夹

```bash
cd your_project
git init
git add .
git commit -m "initial commit"
```

---

### 连接远程仓库

```bash
git remote add origin https://github.com/用户名/仓库名.git
git branch -M main
git push -u origin main
```

---

### 常见错误（你之前遇到的）

#### ❌ 用户名未设置

```bash
git config --global user.name
```

#### ❌ 权限问题

解决：

* 使用 **Personal Access Token (PAT)** 替代密码

# 六、日常开发工作流（核心）

## Daily Workflow

```bash
git pull          # 拉取最新代码
git add .         # 添加修改
git commit -m "message"
git push          # 推送
```

---

# 七、分支管理（非常重要）

## Branching Strategy

### 创建分支

```bash
git checkout -b feature/login
```

### 切换分支

```bash
git checkout main
```

### 合并分支

```bash
git merge feature/login
```

---

### 推荐分支模型

| 分支        | 用途   |
| --------- | ---- |
| main      | 生产环境 |
| dev       | 开发   |
| feature/* | 功能开发 |

---

# 八、Pull Request（团队协作核心）

## Pull Request

流程：

1. 创建分支
2. 提交代码
3. Push 到 GitHub
4. 创建 PR
5. Code Review
6. Merge

# 十三、常见问题

## Common Problems

### 1. push 被拒绝

```bash
git pull --rebase
```

---

### 2. 撤销提交

```bash
git reset --soft HEAD~1
```

---

### 3. 删除远程分支

```bash
git push origin --delete branch_name
```
